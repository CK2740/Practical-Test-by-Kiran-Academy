SECTION B - Generative AI & LLM Concepts
Q11. What does LLM stand for?
Ans: Large Language Model
Q12. What is Generative AI?
Ans: AI that creates new content (text, images, audio, video, code) from patterns learned in data.
Q13. What is a prompt in Generative AI?
Ans: The input/instruction you give an AI model.
Q14. What is a system prompt?
Ans: Hidden instructions that set the AI's role, rules and behavior.
Q15. What is an AI hallucination?
Ans: When AI confidently gives false or made-up information.
Q16. What is a token in an LLM?
Ans: A small chunk of text (word/part of a word) that the model processes.
Q17. What does context window mean?
Ans: The max amount of text (tokens) a model can handle at once.
Q18. What is inference in AI?
Ans: Using a trained model to generate outputs/predictions.
Q19. What is fine-tuning?
Ans: Further training a pre-trained model on specific data for a specific task.
Q20. What does multimodal AI mean?
Ans: AI that understands/generates multiple types of data (text, image, audio, video).

SECTION C - Agents, RAG & Modern AI Development
Q21. What is an AI agent?
Ans: An AI system that plans and takes actions with tools to achieve a goal.
Q22. What is the main difference between a chatbot and an AI agent?
Ans: A chatbot only replies; an agent acts autonomously to complete tasks.
Q23. What does RAG stand for?
Ans: Retrieval-Augmented Generation
Q24. Why is RAG used with LLMs?
Ans: To give the LLM up-to-date/private data and reduce hallucinations.
Q25. What is an embedding?
Ans: A numerical vector representing the meaning of text/images.
Q26. What is a vector database used for in AI applications?
Ans: Storing and searching embeddings by similarity.
Q27. What does tool calling allow an AI model to do?
Ans: Call external functions/APIs/tools (search, database, code, etc.).
Q28. What does MCP stand for in modern AI application development?
Ans: Model Context Protocol
Q29. What is an API key used for?
Ans: To authenticate and authorize access to an API/service.
Q30. What is meant by an agentic workflow?
Ans: A multi-step process where AI plans, uses tools, checks results and iterates.
